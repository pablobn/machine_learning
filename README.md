# Machine Learning Methods – exercise projects

| Project | Notebook | Dataset |
|---|---|---|
| 1 – Linear regression | `linearregression_project_1.ipynb` | Craigslist used cars (regression, target `price`) |
| 2 – Logistic regression | `logisticregression_project_2.ipynb` | HR Analytics – job change (classification, target `target`) |
| 3 – SVM (regression) | `svm_project_3_regression.ipynb` | Craigslist used cars |
| 3 – SVM (classification) | `svm_project_3_classification.ipynb` | HR Analytics – job change |

## Datasets
- Linear regression / SVR -> https://www.kaggle.com/datasets/austinreese/craigslist-carstrucks-data (`vehicles.csv`, too big for GitHub: download it and put it next to the notebooks)
- Logistic regression / SVC -> https://www.kaggle.com/datasets/arashnic/hr-analytics-job-change-of-data-scientists (`aug_train.csv`, included in the repository)
